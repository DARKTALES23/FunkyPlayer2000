# FunkyPlayer2000

**A desktop music player with an early-2000s soul.**
Play your local files or stream from YouTube Music, watch a real-time spectrum analyzer, and sing along with word-by-word synced lyrics.

## Features

* **Y2K look and feel**: Windows XP "Luna" styling, a glossy blue header, bevelled buttons, a zebra-striped playlist and an LED-style spectrum analyzer.
* **Local files**: play `mp3`, `flac`, `ogg`, `opus` and `wav`. Tags (artist, title, album, year, track number) and cover art (embedded or `cover.jpg` / `folder.jpg` next to the files) are read automatically.
* **YouTube Music**: search and import albums, songs and playlists, or paste a YouTube Music link. No account or login needed.
* **Synced lyrics**: fetched from [LiriQo](https://github.com/AlFarrizi-Studio/LiriQo), with [LRCLIB](https://lrclib.net) as a fallback. When word- or syllable-level timing is available, the words light up as they are sung (karaoke style).
* **Real spectrum analyzer**: computed from the audio actually being played. Click it to switch to an oscilloscope view.
* **Album import**: add a whole folder from disk (sorted by track number) or a whole album/playlist from YouTube Music.
* **Smooth playback**: the next YouTube track is pre-loaded while the current one plays.
* **Easy to install**: a Windows installer (with matching Y2K artwork) is generated by one script.

## Install (Windows)

1. Download `FunkyPlayer2000-Setup.exe` from the [Releases](../../releases) page.
2. Run it and follow the wizard. It installs for your user only, so no administrator password is needed.
3. If you do not have [Deno](https://deno.com) or Node.js, the installer offers to install Deno for you. It is required to play from YouTube Music (see [How YouTube playback works](#how-youtube-playback-works)).

> No release yet? Build the installer yourself, see \[Building the installer](#building-the-installer).

## Run from source

Works on Windows, macOS and Linux.

```bash
git clone https://github.com/<your-user>/FunkyPlayer2000.git
cd FunkyPlayer2000
python instalar.py          # installs and checks the dependencies
python funkyplayer2000.py   # starts the player
```

**Requirements**

* Python 3.9+ with `tkinter`
* [Deno](https://deno.com) (recommended) or Node.js 20+, only for YouTube Music playback
* Linux only: `libportaudio2` and `libsndfile1`
(`sudo apt install python3-tk libportaudio2 libsndfile1` on Debian/Ubuntu)

`instalar.py` installs the Python packages, checks for the system requirements above and prints how to fix anything that is missing. If it needs to, it creates a local `.venv` and shows the exact command to launch the player from it.

Python packages: `numpy`, `sounddevice`, `soundfile`, `requests`, `pillow`, `mutagen`, `ytmusicapi`, `yt-dlp\[default]`, `imageio-ffmpeg`.

## Using the player

|Action|How|
|-|-|
|Add local files|**Adicionar…**|
|Add a folder as an album|**Pasta…**|
|Import from YouTube Music|**Importar álbum…** (search, or paste a link)|
|Play a track|Double-click it, or select it and press `Enter`|
|Play / pause|`Space` or the transport buttons|
|Remove a track|Select it and press `Delete`|
|Seek|Drag the position slider|
|Switch visualizer|Click the analyzer|
|Lyrics|**Letra** tab|

The import window accepts:

* searches for **albums**, **songs** or **playlists**;
* links such as `music.youtube.com/watch?v=…`, `music.youtube.com/playlist?list=…`, `music.youtube.com/browse/MPRE…` or `youtu.be/…`.

A **Demo** button adds a synthesized test track, handy for checking the audio output and the visualizer without any files.

## How YouTube playback works

There is no official YouTube Music API, so FunkyPlayer2000 combines two community projects:

* [`ytmusicapi`](https://github.com/sigma67/ytmusicapi) finds albums, songs and playlists (public data only, no login).
* [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) downloads the audio, which is decoded with FFmpeg (bundled through `imageio-ffmpeg`) and played by the app's own audio engine. That is why the spectrum analyzer and seeking work exactly as they do for local files.

A track takes a few seconds to download before it starts. The next one is fetched in the background to hide that delay.

Because these tools are unofficial, they can break when YouTube changes something. If playback stops working, update them:

```bash
python instalar.py      # from source: upgrades yt-dlp and friends
# installed app: download the latest release, or rebuild with `python build.py`
```

`yt-dlp` also needs a JavaScript runtime (Deno or Node.js 20+) to solve YouTube's challenges.

## Building the installer

Produces a standalone app (no Python needed) and a Windows setup wizard.

**You need:** Windows, Python 3.9+ with `tkinter`, and [Inno Setup 6](https://jrsoftware.org/isdl.php) (free).

```bash
python build.py
```

The script installs the build dependencies, runs PyInstaller (`dist/FunkyPlayer2000/`) and then Inno Setup. The installer is written to `installer\_out/FunkyPlayer2000-Setup.exe`. Without Inno Setup, the script still builds the app itself.

The installer script is [`installer.iss`](installer.iss) and the artwork lives in [`assets/`](assets).

## Troubleshooting

* **A YouTube track will not play**: run `python instalar.py` to update `yt-dlp`, and make sure Deno or Node.js 20+ is installed. If you just installed Deno, restart the app (or log out and back in).
* **"ffmpeg not found"**: re-run `python instalar.py`. FFmpeg is installed through `imageio-ffmpeg`.
* **No sound / audio error on Linux**: install `libportaudio2`.
* **`tkinter` missing**: install your platform's Tk package (for example `python3-tk` on Debian/Ubuntu, or reinstall Python on Windows with *tcl/tk and IDLE* ticked).
* **`.m4a` / `.aac` files will not load**: those formats are not supported for local files. Convert them to `mp3`, `flac` or `ogg`.
* **No lyrics found**: not every track has them. Try another version of the song; the source and sync level are shown under the lyrics.
* **Something crashed**: details are saved to `\~/.funkyplayer2000/erro.log` (on Windows: `C:\\Users\\<you>\\.funkyplayer2000\\erro.log`). Please attach it when opening an issue.
